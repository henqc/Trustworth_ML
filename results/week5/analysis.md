## A. Absolute error on the evaluation neighborhood

var_w = sum(w (f - fbar_w)^2) / sum(w) on each case's 200-record dev neighborhood with w = exp(-d^2 / width^2) (the weighted-R^2 denominator per unit weight); weighted MSE = (1 - fidelity) * var_w, RMSE = sqrt(MSE) per explanation, then seed mean per case. Neighborhood check: the rebuilt median width equals grid.csv's `width` for all 600 cases (all 36000 rows), max |difference| 4.4e-16 (assert < 1e-9). Per-case var_w: `eval_variance.csv`.
